# Maintenance and scientific review: 21 October 2026

This review checked the current README, authored guides, ten-rate model translation, observation-selection code, numerical verifier and saved results. The [20 October review](review-2026-10-20.md), original model, search records and historical outputs are preserved. This is a targeted recheck, not a new systematic review or a real-cell validation.

## Scientific and mathematical checks

The exact BioModels XML was retrieved again from its pinned official mirror: its 28,541 bytes and SHA-256 match the bundled model. The rate equations, five-state conservation reduction, fraction readouts and stated fixed parameters were checked against the implementation. Bayesian updates use the declared common Gaussian noise scale. The entropy and log-parameter error definitions match the calculations; the selection score is weighted variance of the noiseless mean, not exact expected information gain.

The 49-hypothesis, 72-candidate, 12-observation comparison and the one off-grid generating setting remain as documented. The off-grid setting is inside the parameter ranges and retains the same noise model. It therefore tests discretization mismatch, not different biological mechanisms or broad robustness. The curve-RMSE time set includes queried times and remains explicitly described as not wholly held out.

Title, issue year and DOI were rechecked for all six cited papers. The Kholodenko, Blüthgen and Liu abstracts support the limited signaling, sequestration and sequential-selection context used here. Their reported results are not treated as validation of this implementation. The [reference audit](reference-audit.json) records actual rechecks and retains earlier access limits.

## Maintenance and editorial changes

Three tampering tests previously created symbolic links merely to copy immutable fixtures. They now copy files, so all assertions run on ordinary Windows accounts without link privileges. No production model or selection code changed. Removed duplicate punctuation from one machine-readable citation and clarified a sentence introducing Liu et al. The README links this review.

## Validation

Using Python 3.12.10 and pinned dependencies, all 18 tests passed with no skips. The full default benchmark was regenerated separately, its independent replay passed, and all 17 CSV artifacts matched the committed reference at relative tolerance 1e-9 and absolute tolerance 1e-10.

The final matched-model mean curve errors still round to 0.002679 for variance-guided selection, 0.010577 for the fixed schedule, and 0.012998 for random selection. These are simulation summaries across computational seeds. Noise misspecification, broader off-grid settings, different mechanisms, and suitable laboratory measurements remain future work.
