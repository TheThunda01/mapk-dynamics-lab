# Assumptions and their consequences

This benchmark evaluates a simulated decision rule. The generating equations, allowed hypotheses and artificial observation process are explicit choices, not discoveries about a measured pathway.

The register separates evidence about the input from choices made for this analysis. “Checked” means only the stated check passed; it does not establish experimental validity.

| Assumption | Why it is used and what supports it | Check and consequence if it fails |
| --- | --- | --- |
| The pinned BioModels encoding is the intended model. | It is an accessible implementation of the Kholodenko (2000) compact feedback cascade. Pinning avoids silent curation changes. | Three upstream hashes, structure and source-MathML rates are checked. The canonical BioModels web page was not accessible in the initial provenance review; the official mirror is the inspected input. |
| A fixed three-layer cascade without explicit complexes is adequate for this simulation question. | Compactness makes translation and policy evaluation inspectable. It is a modeling simplification, not a biological adequacy claim. | Blüthgen et al. (2006) provide contrary evidence that sequestration can alter behavior. No explicit-complex or real-cell comparison is implemented. |
| Layer totals and compartment size remain constant. | The source contains interconversions, no synthesis/degradation, and a fixed unit-sized compartment. | Conservation, nonnegativity tolerances and a five-state reduced implementation are checked. Changing abundance or volume would require different equations. |
| The source’s numerical units can be used internally. | The XML declares substance units but leaves several rate-parameter units implicit. Fractions avoid assigning new assay units. | Source annotations were inspected. Numerical values are not transferred to a physical measurement protocol or assumed to be calibrated concentrations. |
| Only V1 scale and Ki vary; every other parameter and initial value is known. | Two directions keep the grid small enough to inspect. This is a pragmatic benchmark choice. | The manifest and exported hypotheses make the restriction explicit. Unknown other constants could create ambiguities that the current posterior cannot express. |
| The 7×7 uniform grid is a useful finite comparison. | Equal weights avoid introducing an additional preference among its 49 points. They are not an empirically elicited biological prior, nor generally uniform in logarithmic coordinates. | Grid ranges and weights are checked. Narrower/broader grids or other priors can change outcomes and policy rankings. |
| Matched-model truth lies on the grid. | The 20 seed-indexed truths are deliberately drawn from allowed hypotheses to provide a controlled comparison. | Recorded truth IDs and generator seeds are checked. This favors a correctly specified hypothesis set and does not establish performance on real observations. |
| Artificial errors are additive independent Gaussian with known SD 0.04. | A simple shared likelihood isolates observation choice. The simulator uses the same model as inference in both scenarios. | Noise is regenerated by the verifier. No assay evidence supports the value; heteroscedasticity, bias, dependence or unknown SD are untested. Values are not clipped to [0,1]. |
| The 72 candidates have equal cost and each may be measured once. | Each candidate is one readout/time pair. Equal costs and a budget of 12 make policies directly comparable. | Selected IDs are unique; the first two are shared, and the policy cannot inspect unrevealed values. Correlated repeated measurements, costs and failures are absent. |
| Common truth and candidate-indexed noise give a fair paired comparison. | Each policy sees the same possible outcomes for a given seed, limiting noise differences between policies. | The verifier regenerates pools and choices. Seeds are computational repeats, not independent biological replicates or a population sample. |
| Weighted latent variance is a worthwhile selection heuristic. | It prefers candidates where currently weighted hypotheses disagree. It is not exact expected information gain or a globally optimized schedule. | Acquisition is replayed independently. It can focus on differences irrelevant to the evaluation target or ignore unsupported alternatives. |
| Curve RMSE and grid metrics describe the stated goal. | RMSE evaluates posterior mean fractions at 81 times; entropy and parameter error describe the finite grid. | Metrics are recomputed. The time set includes queried observations and a later interval, so it is not purely held out; low entropy does not certify correctness. |
| One off-grid truth is a useful discretization check. | V1 scale 1.05 and Ki 9.75 are between default points but inside both ranges. Six noise repeats isolate a missing-point case with unchanged equations and error scale. | True-point mass is omitted. This does not test out-of-range extrapolation, different mechanisms or broad robustness. |
| The chosen numerical settings are adequate for the declared experiment. | BDF, tighter BDF/Radau, source-rate checks and a conservation-reduced formulation provide complementary numerical evidence (SciPy, 2026). | Baseline agreement is checked through time 4000; all trajectories have finite/conservation checks. Agreement of every solver at every possible parameter is not established. |
| Output replay and fresh reruns cover different reproducibility questions. | The verifier checks saved likelihoods, choices, metrics, keys and hashes; full reruns regenerate trajectories for CSV comparison. | A self-consistent manifest is not authentication, and the verifier alone does not re-integrate every trajectory. Partial or failed output must not be used as a complete run. |

The [primary studies](references.md) motivate the model and limitations. None validates this project’s policy ranking, selected noise scale, finite prior or suitability for laboratory decision-making.
